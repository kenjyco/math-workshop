# Foundational examples

This directory is reserved for Stage C implementation of the approved mathematics goals. No worked-example corpus has been implemented in this starter.

Use the formats chosen in the approved plan to express exact mathematical reasoning, clear notation, appropriately labeled visuals, and concise parent bridges. Favor simple editable content with enough structure to verify and reuse later. Do not introduce the full application stack just to display these examples.

Verify intermediate steps, representation meaning, units, edge cases, grade boundaries, and final answers. Keep complete examples distinct from future teaching scripts and interactive activities. Use small purposeful annotations; avoid a routine lesson or README for every goal.
