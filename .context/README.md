# Agent context entrypoint

This directory is the portable entrypoint for agents working on Math Workshop V2. All links below stay inside this repository.

## Reading order

1. [Repository instructions](../AGENTS.md).
2. [North Star](../NORTH_STAR.md).
3. [Project overview](../README.md).
4. [Goal conventions](../goals/README.md), then the specific approved goal(s) when they exist.
5. [Worked examples](../examples/README.md), then the relevant content and verification assets when they exist.

The current owner instruction determines the authorized stage. Do not infer authorization from the presence of this scaffold or a future-work description. Research/planning, goal authoring, foundational implementation, teaching, and interactive work are distinct passes.

Prioritize mathematical correctness and coverage, concise parent bridges, free concept exploration, and standalone project portability. Do not create application architecture to compensate for an incomplete content plan. Do not duplicate operational status or session reports here.

No external workspace, personal reference directory, AI wrapper, or private file is required to read and understand this project. When working on a standalone checkout without operational context, state what stage authorization is missing instead of guessing or inventing project history.

The [worked evidence map](../goals/worked-evidence.json) assigns each record or section to its contract. The [search catalog](../search/catalog.json) records the terms, relationship and order for each claim. Chapter claims also identify a supporting worked section. The builder checks these assignments against chapter citations and contract grades before writing the display and matching fields used in the browser.
