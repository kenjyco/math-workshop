# Consequential decisions

- **2026-10-21 — independent local foundation.** One child Git repository inside a
  non-Git workspace. No prior application imported or inspected. No commits until
  explicit owner acceptance and later commit authorization. This preserves the
  owner's review boundary while allowing full implementation and QA.
- **Go + Svelte + SQLite.** Go owns truth/persistence; Svelte owns interaction;
  Vite emits embedded assets. database/sql with modernc supports the observed
  darwin/arm64 host without a runtime C toolchain. One connection and rollback
  journaling avoid unnecessary concurrency/backup complexity. No ORM, SSR or Node
  service; no stack-comparison detour.
- **Finite activity contracts.** Independent addends 0–5 correct the approved two-hand
  counting scope; the pad spans 0–10 for every default problem. Typed embedded
  definitions and pinned math-v2 rules parameterize both activities, with factor
  total 24 still the shipped default. Immutable revision-1 bodies and a narrow
  math-v1 resolver preserve old meaning. Schema 2 replaces only the original
  seeded settings with meaningful lesson references. Adult selection and equal-group
  teaching remain goals 001/002; no numbered goal is completed by parameterization.
- **Independent attempts and monotonic help.** An answer does not depend on the
  autosave queue finishing. Attempts freeze semantic input and replay safely.
  Help is recorded before reveal outside undoable drafts, preserving provenance
  through stale-tab recovery. Discoveries are derived from correct attempts.
- **Full-size long rectangles.** A scrollable 48-pixel editing grid with buttons
  and focus scrolling preserves honest dimensions. No miniature editing grid,
  wrapping, auto-rotation or implicit repacking.
- **Manifest identity without commits.** An explicit allowlist exports clean source and
  locks. Generated records are excluded to avoid circular hashes. An archive checksum
  identifies bytes independently of source identity. No claim of byte reproducibility or
  invented Git SHA.
- **Verification remains labeled.** Host automation, rendered inspection and an
  owning-agent adversarial self-review are distinct from human acceptance or
  actual device testing. Optional consultation never supplies owner acceptance.
- **Goal order.** Keep setup, factor extension, area models, fluency, content
  updates, portable release and evidence-led improvements in that sequence.
  Ordering is practical, not a claim all goals technically depend on their prior
  number. Real family observations are a hard input for goal 007. Later scope/order
  changes must preserve their reason here rather than rewriting history silently.
- **Source and run-record boundary.** Durable guides and tests belong in source;
  local handoffs and generated run results are external, optional context. This
  supersedes keeping preview reports in the checkout and preserves clone portability.
- **Public target versus internal builds.** VERSION sets the first intended public
  target to 0.1.0; explicit dev.N packages identify internal iterations. This replaces
  incrementing preview patch versions and keeps goal progress separate from releases.
