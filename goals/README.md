# Implementation goals

This directory is reserved for Stage B goal authoring after the Stage A plan is reviewed and accepted. No implementation goals have been authored in this starter.

An eventual goal should specify a coherent piece of mathematical content: intended outcome, scope, standard/concept IDs, prerequisites, numeric and grade boundaries, example/representation requirements, parent-bridge placement, source references, and objective verification/completion criteria. State exclusions that preserve the current phase.

Goals should be independently understandable and ordered for implementation, while the eventual learner remains free to explore. Do not force one goal per standard, example, lesson, or commit. Keep operational progress, dispatch records, session reports, and commit plans outside the repository.
