# Math Workshop V2

A connected mathematics foundation for kindergarten through fourth grade, designed to support an eventual activity-first workshop where learners can start at their current level, explore freely, and ask for help without losing their work.

The initial content pass establishes accurate mathematical definitions, worked examples, visual representations, and short parent bridges connecting different ways of expressing the same mathematics. Teaching explanations and interactive activities are later passes built from that verified foundation.

## Content principles

Preserve official standard identifiers and sources, distinguish requirements from explanatory choices, and check both the mathematical result and the reasoning that produces it. Concepts can span multiple grades while examples retain clear grade-specific scope and numeric limits.

Parent bridges belong with the foundational examples. They should be concise and specific; full teaching explanations come afterward. Later activities can combine several concepts and should provide focused help with optional connections to foundational, related, and next ideas.

All content and links needed to understand this repository belong inside it. Development-session records and private reference materials are not project dependencies. The provisional future application stack is Go, SQLite, and Svelte; the example-first work does not require that application to be built.
